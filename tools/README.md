# Звук роликов

`assets/video/hero-ru.mp4` и `hero-en.mp4` — двоичные файлы, и без
исходников их не поправить: чтобы сделать музыку тише, пришлось бы
пересобирать всё с нуля. Здесь лежит то, из чего они собраны.

```bash
python3 tools/film-audio.py     # → tools/build/music.wav, pen-ru.wav, pen-en.wav
./tools/film-mix.sh             # → assets/video/hero-*.mp4
```

Громкость слоёв — переменными окружения:
`GM` музыка (0.26), `GP` перо (0.68), `DUCK` приседание музыки под
голосом (0.32).

## Из чего собрана дорожка

**Голос** — из съёмки, `tools/source/voice-*.m4a`. Уровень не тронут
вовсе: это по-прежнему главное в ролике. Дорожки вырезаны из первых
версий роликов копией потока, без перекодирования.

**Перо** звучит ровно там, где пишет. Интервалы сняты покадрово
с самих роликов и вписаны в конец `film-audio.py`: в русском
0,45–2,58 («Привет»), 2,68–2,94 (восклицательный знак) и 3,28–5,46
(«Как дела?»); в английском свои. На точке знака — короткий удар пером.
Сам звук — шумовая полоса с резонансом около 4 кГц, огибающая дрожит
случайной прогулкой (нажим), между буквами редкие отрывы.

**Музыка** — войлочное пианино поверх подушки Dmaj9 → Bm7 → Gmaj9
и возврата к D. Восемь нот на девять секунд: под музыкой говорит голос,
а в кадре и без того много движения. Реверб — Шрёдер, разные линии
задержки слева и справа, оттуда же ширина.

**Ничего чужого.** Звук синтезирован целиком, сэмплов со стороны нет —
и вопроса о лицензии на сайте тоже нет.

## Что легко сломать

- **Второй прогон по готовому ролику.** `film-mix.sh` берёт голос
  из `tools/source/`, а не из `assets/video/`. Если поменять это
  местами, музыка подмешается к музыке.
- **`alimiter` без `level=disabled`.** По умолчанию он подтягивает
  результат обратно к 0 dBFS, и ограничитель работает усилителем:
  просишь пик −1,5 dBFS, получаешь −0,4.
- **Окна приседания** в `film-mix.sh` относятся к конкретным дорожкам.
  Сменили озвучку — снимите их заново:
  `ffmpeg -i tools/source/voice-ru.m4a -af silencedetect=noise=-45dB:d=0.2 -f null -`

## Чем проверялось

Ушей у сборщика не было, поэтому всё измерялось:

- уровни по кускам (`volumedetect` на окне голоса, на окне пера, на хвосте);
- приседание — отдельным прогоном одной музыки: −34 dB под голосом
  против −29 dB без него;
- итог по EBU R128: −19,5 LUFS (ru) и −18,0 LUFS (en), пик −2,8
  и −1,4 dBFS. Тише привычных −16…−14 LUFS сети намеренно: ролик
  включают руками, пугать им человека незачем;
- спектрограмма и осциллограмма — перо стоит ровно в интервалах письма,
  музыка не лезет выше 2,5 кГц.
